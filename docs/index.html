01 / PURPOSE

The engineering problem

Market depth moves quickly.
Research needs memory.

Polymarket’s live feed tells you what the book looks like now. This recorder preserves what it looked like over time—every price level, every outcome, every five seconds—so the session can be analyzed after the event.

It is intentionally local-first: one configuration file, no wallet, no API key, and no database to operate.

A small, resilient pipeline

From event URL to
analysis-ready rows.

04 / BUILD NOTES

Designed for failure, not just the happy path

Quietly robust.

The recorder assumes networks disconnect, processes get interrupted, and long-running sessions should not depend on fragile in-memory state.

Read the implementation ↗
01

Exponential reconnects

Jittered backoff grows from one to sixty seconds and resets after a healthy connection.

02

Crash-tolerant rows

Every JSONL line is independently valid, flushed, and synced before the next interval.

03

Honest data freshness

Connection state and per-book update timestamps stay in the output during recovery.

04

Portable operation

Run with one Windows launcher, a Python command, Docker Compose, or any long-lived host.
